# Changelog - ArnTCLI 0.1
## 0.1.0 - 2026-10-19
### Features
- Initial project scaffolding for ArnTCLI (offline-first Android terminal emulator).
- Standardized Android build infrastructure with Gradle 9.1 and AGP 9.0.
- Automated `VerifyAndroidRulesTask` integration enforcing design rules AR-001 through AR-016.
- Integration of the Elms Sans typography suite (`elms_sans_bold`, `elms_sans_light`, `elms_sans_medium`).
- Electric Slate dark theme tokens, spring physics engine, and centralized UI presets.
- Configuration and profile import/export scaffolding.
